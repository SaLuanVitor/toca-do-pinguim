# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, critique ideias e código, não quem os escreveu, e
não tolere assédio. O texto completo no link acima vale para issues, PRs, discussões e
qualquer espaço do projeto.

Para relatar um comportamento que viole o código, use o relato privado da aba **Security**
do repositório, como no [SECURITY.md](SECURITY.md), indicando que é sobre conduta. Quem
mantém o projeto responde e mantém o relato em sigilo.
